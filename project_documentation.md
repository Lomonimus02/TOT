# Документация проекта "Пирамида ТОТА"

## Обзор проекта

Веб-сайт "Пирамида ТОТА" — это современный адаптивный сайт, посвященный духовному центру с пирамидой и храмом. Сайт предоставляет информацию о программах, услугах и возможностях для духовного развития.

## Интеграция с Telegram

### Настройка бота:
1. Создать бота через @BotFather
2. Получить токен бота
3. Настроить chat_id для получения сообщений
4. Обновить переменные в forms.js:
   ```javascript
   this.telegramBotToken = 'YOUR_BOT_TOKEN';
   this.telegramChatId = 'YOUR_CHAT_ID';
   ```

### Типы сообщений:
- **Обратная связь** — отправляет имя, email, телефон и сообщение
- **Подписка на рассылку** — отправляет email подписчика
- **Заявки на программы** — отправляет данные о записи на мероприятия

## Inline редактор контента

### Реализованные возможности:
- **Базовый шаблон страниц** (template.html) - универсальный шаблон для создания новых страниц
- **Полный набор страниц** - созданы все страницы из картушей главной страницы
- **Очищенные существующие страницы** - удален весь референсный контент, остались только заголовки и навигация
- **Готовность к редактированию** - все страницы полностью пустые, контент добавляется только через редактор
- **Встроенный InlinePageEditor** - система inline редактирования для администраторов
- **Автоматическое сохранение в БД** - мгновенное сохранение изменений в базу данных SQLite
- **API сервер** - Node.js/Express сервер для обработки запросов редактора
- **Fallback режим** - автоматическое переключение на localStorage при недоступности API

### Система автоматического сохранения:

**API Сервер (Node.js/Express):**
- Автоматическое сохранение изменений в SQLite базу данных
- Мгновенное сохранение с задержкой 1 секунда после изменения
- Batch API для быстрого сохранения множественных изменений
- Версионирование контента с историей изменений
- Fallback на localStorage при недоступности сервера

**База данных (SQLite):**
- `page_content` - основной контент страниц
- `content_versions` - история изменений
- `page_settings` - настройки страниц (заголовки, мета-данные)

**Клиентская часть:**
- Автоматическое определение доступности API
- Мгновенные индикаторы сохранения/ошибок
- Автоматическая загрузка контента при открытии страницы
- Поддержка создания новых блоков с сохранением в БД
