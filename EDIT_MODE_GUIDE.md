# Руководство по режиму редактирования сайта "Пирамида ТОТА"

## Обзор

Режим редактирования позволяет администраторам редактировать контент сайта в реальном времени без необходимости изменения HTML файлов напрямую. Все изменения сохраняются в базе данных и применяются автоматически.

### ✨ Новые возможности (обновление):

- **Визуальные кнопки управления** для каждого элемента
- **Drag & Drop** перемещение элементов
- **Улучшенная панель инструментов** с индикаторами
- **Контекстные подсказки** и справочная система
- **Галерея изображений** для выбора из существующих файлов
- **Горячие клавиши** для быстрого управления

## Доступ к режиму редактирования

### Учетные данные администратора
- **Email:** admin@gmail.com
- **Пароль:** admin123

### Как войти в режим редактирования

1. Откройте любую страницу сайта
2. Нажмите кнопку "Вход" в правом верхнем углу
3. Введите учетные данные администратора
4. После успешной авторизации в навигации появится кнопка "Редактировать"
5. Нажмите кнопку "Редактировать" для включения режима редактирования

## Функциональность режима редактирования

### Основные возможности

1. **Редактирование текста**
   - Кликните на любой текстовый элемент для начала редактирования
   - Элементы подсвечиваются при наведении
   - Поддерживается редактирование заголовков, параграфов, ссылок меню

2. **Добавление текстовых блоков**
   - Нажмите кнопку "➕ Добавить текстовый блок" в панели инструментов
   - Введите текст в появившемся диалоге
   - Новый блок будет добавлен в конец страницы

3. **Загрузка изображений**
   - Нажмите кнопку "🖼️ Добавить изображение" в панели инструментов
   - Выберите изображение с компьютера (максимум 5MB)
   - Изображение будет загружено и добавлено на страницу

4. **Удаление элементов** ⭐ НОВОЕ
   - Наведите на элемент и нажмите кнопку 🗑️
   - Или выберите элемент и нажмите клавишу Delete
   - Подтвердите удаление в диалоговом окне
   - Поддерживается удаление всех типов элементов

5. **Перемещение элементов** ⭐ НОВОЕ
   - **Кнопки:** используйте ⬆️⬇️ при наведении на элемент
   - **Drag & Drop:** перетащите элемент в нужное место
   - **Горячие клавиши:** Ctrl+↑/↓ для выбранного элемента
   - Визуальные индикаторы показывают место вставки

6. **Загрузка изображений** ⭐ УЛУЧШЕНО
   - **Загрузка с компьютера:** выберите файл с устройства
   - **Галерея:** выберите из уже загруженных изображений
   - Поддержка форматов: JPG, PNG, GIF, WebP
   - Максимальный размер: 5MB

7. **Сохранение изменений**
   - Нажмите кнопку "💾 Сохранить" для сохранения всех изменений
   - Используйте горячую клавишу Ctrl+S
   - Кнопка активна только при наличии изменений
   - Анимация пульсации указывает на несохраненные изменения

8. **Отмена изменений**
   - Нажмите кнопку "❌ Отменить" для отмены всех несохраненных изменений
   - Кнопка активна только при наличии изменений

### Панель инструментов

Панель инструментов появляется внизу экрана при включении режима редактирования и содержит:

- **💾 Сохранить изменения** - сохранить все изменения в базу данных
- **❌ Отменить изменения** - отменить все несохраненные изменения
- **➕ Добавить текстовый блок** - добавить новый текстовый блок
- **🖼️ Добавить изображение** - загрузить и добавить изображение
- **🗑️ Удалить элемент** - удалить выбранный элемент
- **Счетчик изменений** - показывает количество несохраненных изменений

### Горячие клавиши ⭐ РАСШИРЕНО

- **Ctrl+S** - сохранить изменения
- **Escape** - выйти из режима редактирования
- **Delete** - удалить выбранный элемент
- **Ctrl+↑** - переместить выбранный элемент вверх
- **Ctrl+↓** - переместить выбранный элемент вниз

### Справочная система ⭐ НОВОЕ

- **❓ Справка** - кнопка в панели инструментов
- **Контекстные подсказки** появляются при первом использовании
- **Визуальные индикаторы** для всех интерактивных элементов
- **Статус-бар** показывает количество изменений и элементов

- Доступ к режиму редактирования имеют только пользователи с ролью "admin"
- Кнопка "Редактировать" видна только администраторам
- Все API защищены JWT токенами
- Проверка прав администратора на серверной стороне

## Техническая информация

### Файлы системы редактирования

- `js/edit-mode.js` - основной модуль режима редактирования
- `css/style.css` - стили для режима редактирования (в конце файла)
- `server.js` - серверные API для управления контентом
- `create-admin.js` - скрипт для создания администратора

### База данных

Изменения сохраняются в таблицах:
- `content_changes` - изменения контента элементов
- `element_formatting` - форматирование элементов
- `users` - пользователи и администраторы

### API endpoints

- `GET /api/content/:pageId` - получение контента страницы
- `POST /api/content/save` - сохранение изменения элемента
- `POST /api/content/batch-save` - пакетное сохранение изменений
- `DELETE /api/content/:pageId/:elementId` - удаление элемента
- `POST /api/upload/image` - загрузка изображения

## Устранение неполадок

1. **Кнопка "Редактировать" не видна**
   - Убедитесь, что вы вошли как администратор
   - Проверьте роль пользователя в админ-панели

2. **Изменения не сохраняются**
   - Проверьте подключение к интернету
   - Убедитесь, что сервер запущен
   - Проверьте консоль браузера на наличие ошибок

3. **Изображения не загружаются**
   - Проверьте размер файла (максимум 5MB)
   - Убедитесь, что файл является изображением
   - Проверьте права доступа к папке images/uploads
