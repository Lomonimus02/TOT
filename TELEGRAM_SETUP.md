# 🤖 Настройка Telegram бота для сайта

## 📋 Пошаговая инструкция

### 1️⃣ Создание бота
1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Введите название бота: `Pyramid TOTA Bot`
4. Введите username бота: `pyramid_tota_bot` (или любой доступный)
5. Сохраните полученный **токен бота** (например: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2️⃣ Получение Chat ID
1. Напишите вашему боту любое сообщение (например: "Привет")
2. Откройте в браузере: 
   ```
   https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates
   ```
   Замените `<YOUR_BOT_TOKEN>` на ваш токен
3. Найдите в ответе `"chat":{"id":123456789}` - это ваш **Chat ID**

### 3️⃣ Настройка переменных окружения в Render
Добавьте в Environment Variables:
```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_CHAT_ID=ваш_chat_id
```

### 4️⃣ Проверка работы
После развертывания на Render:
1. Заполните любую форму на сайте
2. Проверьте, что сообщение пришло в Telegram

## 🔧 Дополнительные настройки

### Настройка команд бота (опционально)
1. Отправьте @BotFather команду `/setcommands`
2. Выберите вашего бота
3. Отправьте список команд:
   ```
   start - Начать работу с ботом
   help - Помощь
   status - Статус сайта
   ```

### Настройка описания бота
1. `/setdescription` - установить описание
2. `/setabouttext` - установить текст "О боте"

## ⚠️ Важные замечания

1. **Безопасность**: Никогда не публикуйте токен бота в открытом коде
2. **Лимиты**: Telegram Bot API имеет лимиты на количество сообщений
3. **HTTPS**: Формы работают только по HTTPS (Render автоматически предоставляет SSL)
4. **Тестирование**: Обязательно протестируйте все формы после настройки

## 🔍 Отладка проблем

### Формы не отправляются:
1. Проверьте правильность токена и Chat ID
2. Убедитесь, что переменные окружения установлены в Render
3. Проверьте логи сервера в панели Render

### Сообщения не приходят:
1. Убедитесь, что вы написали боту хотя бы одно сообщение
2. Проверьте, что Chat ID получен правильно
3. Попробуйте отправить тестовое сообщение через API

### Тестовый запрос к API:
```bash
curl -X POST "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/sendMessage" \
     -H "Content-Type: application/json" \
     -d '{"chat_id": "<YOUR_CHAT_ID>", "text": "Тест"}'
```
