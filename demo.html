🤖 Настройка Telegram бота:

  1. Напишите @BotFather в Telegram
  2. Выполните команду /newbot
  3. Следуйте инструкциям для создания бота
  4. Сохраните полученный токен
  5. Напишите боту любое сообщение
  6. Перейдите по ссылке: https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates
  7. Найдите chat_id в ответе
  8. Обновите данные в файле js/forms.js:
this.telegramBotToken = 'YOUR_BOT_TOKEN'; this.telegramChatId = 'YOUR_CHAT_ID';
⚠️ Важно: Для работы Telegram API сайт должен работать по HTTPS. Для локального тестирования формы будут показывать ошибку, но остальная функциональность работает.
