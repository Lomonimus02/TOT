### 📥 Шаг 3: Загрузка файлов проекта с базой данных
После запуска скрипта вам нужно будет загрузить файлы проекта ВКЛЮЧАЯ базу данных в `/var/www/pyramid-tota/`

**Варианты загрузки:**

#### A) Через SCP (рекомендуется)
```bash
# На вашем локальном компьютере - создайте архив с базой данных
tar --exclude='node_modules' --exclude='.git' -czf pyramid-tota-with-db.tar.gz .

# Загрузите архив на сервер
scp pyramid-tota-with-db.tar.gz root@45.90.219.229:/var/www/pyramid-tota/

# На сервере распакуйте
ssh root@45.90.219.229 "cd /var/www/pyramid-tota && tar -xzf pyramid-tota-with-db.tar.gz && rm pyramid-tota-with-db.tar.gz"
```

#### B) Через Git (если проект в репозитории)
```bash
cd /var/www/pyramid-tota
git clone https://github.com/your-repo.git .
# Затем загрузите файлы базы данных отдельно
```

#### C) Через FTP/SFTP
Используйте любой FTP клиент для загрузки файлов.

**⚠️ ВАЖНО**: Убедитесь, что файлы `server/content.db` и `server/database.db` загружены!

### 🔧 Полезные команды
```bash
# Статус приложения
pm2 status

# Логи приложения
pm2 logs pyramid-tota

# Перезапуск приложения
pm2 restart pyramid-tota

# Статус Nginx
systemctl status nginx

# Перезапуск Nginx
systemctl restart nginx
```

### 🛡️ Настройка SSL (только для доменов)
**Важно**: SSL сертификаты работают только с доменами, не с IP-адресами.

Если у вас есть домен:
```bash
certbot --nginx -d yourdomain.com
```

Без домена сайт будет работать по HTTP (это нормально для тестирования).
