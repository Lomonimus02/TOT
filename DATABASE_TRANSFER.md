# 📊 Перенос локальной базы данных на сервер

## 🎯 Краткая инструкция

### Шаг 1: Подготовка локальной базы данных
Убедитесь, что у вас есть файлы базы данных:
```bash
# Проверьте наличие файлов
ls -la server/
# Должны быть:
# - content.db (основная база данных)
# - database.db (дополнительная, если есть)
```

### Шаг 2: Создание архива с базой данных
```bash
# Создайте архив ВКЛЮЧАЯ базы данных
tar --exclude='node_modules' --exclude='.git' -czf pyramid-tota-with-db.tar.gz .

# Проверьте размер (должен быть больше обычного)
ls -lh pyramid-tota-with-db.tar.gz
```

### Шаг 3: Загрузка на сервер
```bash
# Загрузите архив на сервер
scp pyramid-tota-with-db.tar.gz root@45.90.219.229:/var/www/pyramid-tota/

# На сервере распакуйте
ssh root@45.90.219.229 "cd /var/www/pyramid-tota && tar -xzf pyramid-tota-with-db.tar.gz && rm pyramid-tota-with-db.tar.gz"
```

### Шаг 4: Настройка прав доступа
```bash
# На сервере настройте права на базы данных
ssh root@45.90.219.229 "chmod 666 /var/www/pyramid-tota/server/*.db && chown www-data:www-data /var/www/pyramid-tota/server/*.db"
```

### Шаг 5: Перезапуск приложения
```bash
# Перезапустите приложение
ssh root@45.90.219.229 "cd /var/www/pyramid-tota && pm2 restart pyramid-tota"
```
