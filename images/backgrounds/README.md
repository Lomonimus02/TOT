# Фоновые изображения

## Инструкции по добавлению фонового изображения:

1. **Добавьте файл изображения** в эту папку с именем `cosmic-bg.jpg`
2. **Рекомендуемые характеристики:**
   - Разрешение: минимум 1920x1080px (Full HD)
   - Формат: JPG или WebP
   - Размер файла: до 2MB для оптимальной загрузки
   - Стиль: космическая/мистическая тематика

3. **Опционально:** Добавьте версию в формате WebP (`cosmic-bg.webp`) для лучшей оптимизации

## Текущие настройки CSS:

```css
.cosmic-background {
    background-image: 
        url('../images/backgrounds/cosmic-bg.webp'),  /* Приоритет WebP */
        url('../images/backgrounds/cosmic-bg.jpg'),   /* Fallback JPG */
        var(--gradient-cosmic);                       /* Fallback градиент */
}
```

## Поддерживаемые форматы:
- ✅ JPG/JPEG
- ✅ WebP (рекомендуется)
- ✅ PNG (не рекомендуется из-за размера)

После добавления изображения фон автоматически изменится на всех страницах сайта.
