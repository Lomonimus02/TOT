## 🔧 Шаг 1: Подготовка базы данных Neon

### 1.1 Создание проекта в Neon
1. Перейдите на https://neon.tech/
2. Зарегистрируйтесь или войдите в аккаунт
3. Создайте новый проект:
   - **Название**: `pyramid-tota-db`
   - **Регион**: выберите ближайший к вашим пользователям
   - **PostgreSQL версия**: 15 или новее

### 1.2 Получение строки подключения
1. В панели Neon перейдите в раздел **Connection Details**
2. Скопируйте **Connection String** (должна выглядеть примерно так):
   ```
   postgresql://username:password@ep-xxx-xxx.region.neon.tech/neondb?sslmode=require
   ```
3. Сохраните эту строку - она понадобится для настройки Render

### 1.3 Инициализация таблиц
Таблицы будут созданы автоматически при первом запуске сервера благодаря функции `initDatabase()` в `server.js`.

## 🌐 Шаг 2: Развертывание на Render

### 2.1 Создание аккаунта Render
1. Перейдите на https://render.com/
2. Зарегистрируйтесь или войдите через GitHub
3. Подключите ваш GitHub аккаунт

### 2.2 Создание Web Service
1. В панели Render нажмите **"New +"** → **"Web Service"**
2. Выберите **"Build and deploy from a Git repository"**
3. Подключите репозиторий:
   - **Repository**: `Lomonimus02/TOT`
   - **Branch**: `01`
4. Настройте параметры сервиса:
   - **Name**: `pyramid-tota-website`
   - **Region**: выберите ближайший регион
   - **Branch**: `01`
   - **Root Directory**: оставьте пустым
   - **Runtime**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`

### 2.3 Настройка переменных окружения
В разделе **Environment Variables** добавьте:

```bash
NODE_ENV=production
PORT=10000
JWT_SECRET=pyramid_tota_secret_key_2025_CHANGE_THIS
DATABASE_URL=postgresql://your_neon_connection_string_here
```

**⚠️ ВАЖНО**: 
- Замените `DATABASE_URL` на вашу реальную строку подключения из Neon
- Замените `JWT_SECRET` на уникальный секретный ключ

### 2.4 Дополнительные настройки
- **Plan**: выберите **Free** (для начала)
- **Auto-Deploy**: включите для автоматического развертывания при изменениях в ветке `01`

### 3.1 Обязательные переменные

### 3.2 Опциональные переменные (для Telegram интеграции)

## 🚀 Шаг 4: Запуск развертывания

1. Нажмите **"Create Web Service"**
2. Render автоматически:
   - Клонирует ваш репозиторий
   - Установит зависимости (`npm install`)
   - Запустит сервер (`npm start`)
3. Процесс займет 3-5 минут

## ✅ Шаг 5: Проверка развертывания

### 5.1 Проверка статуса
1. В панели Render перейдите к вашему сервису
2. Проверьте логи в разделе **Logs**
3. Убедитесь, что видите сообщения:
   ```
   🚀 Сервер запущен на http://localhost:10000
   📊 База данных Neon PostgreSQL подключена
   🌟 Сайт "Пирамида ТОТА" готов к работе!
   ```

### 5.2 Тестирование сайта
1. Откройте URL вашего сервиса (будет показан в панели Render)
2. Проверьте основные функции:
   - Загрузка главной страницы
   - Переходы между страницами
   - Работа форм (если настроен Telegram)

## 🔧 Шаг 6: Настройка домена (опционально)

### 6.1 Пользовательский домен
1. В настройках сервиса перейдите в **Settings** → **Custom Domains**
2. Добавьте ваш домен
3. Настройте DNS записи согласно инструкциям Render

## 🐛 Устранение неполадок

### Проблема: Сервер не запускается
**Решение**: Проверьте логи на наличие ошибок подключения к БД

### Проблема: База данных недоступна
**Решение**: 
1. Проверьте правильность `DATABASE_URL`
2. Убедитесь, что Neon проект активен
3. Проверьте настройки SSL в строке подключения

### Проблема: Формы не работают
**Решение**: 
1. Проверьте настройки CORS в `server.js`
2. Убедитесь, что сайт работает по HTTPS (Render автоматически предоставляет SSL)
