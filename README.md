# Пирамида ТОТА - Веб-сайт

Современный адаптивный веб-сайт для духовного центра "Пирамида ТОТА" с космическим дизайном и анимированными переходами.

## 🌟 Особенности

- **Адаптивный дизайн** — корректное отображение на всех устройствах
- **Космический фон** — анимированный звездный фон с эффектами
- **Анимированные переходы** — плавные анимации между страницами и элементами
- **Интеграция с Telegram** — отправка заявок через Telegram бота
- **Модальные окна** — система авторизации и регистрации
- **Египетская тематика** — дизайн в стиле древнего Египта

## 🚀 Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/tot-website.git
   cd tot-website
   ```

2. **Откройте index.html в браузере** или разместите на веб-сервере

3. **Настройте Telegram бота:**
   - Создайте бота через @BotFather
   - Получите токен бота и chat_id
   - Обновите данные в `js/forms.js`:
     ```javascript
     this.telegramBotToken = 'YOUR_BOT_TOKEN';
     this.telegramChatId = 'YOUR_CHAT_ID';
     ```

## 🔐 Настройка Telegram бота

1. **Создание бота:**
   - Напишите @BotFather в Telegram
   - Выполните команду `/newbot`
   - Следуйте инструкциям для создания бота
   - Сохраните полученный токен

2. **Получение chat_id:**
   - Напишите боту любое сообщение
   - Перейдите по ссылке: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
   - Найдите chat_id в ответе

3. **Обновление кода:**
   ```javascript
   // В файле js/forms.js
   this.telegramBotToken = 'YOUR_BOT_TOKEN';
   this.telegramChatId = 'YOUR_CHAT_ID';
   ```

## 🐛 Отладка

### Частые проблемы
1. **Формы не отправляются:**
   - Проверьте токен и chat_id Telegram бота
   - Убедитесь, что сайт работает по HTTPS

2. **Анимации не работают:**
   - Проверьте поддержку браузером
   - Убедитесь, что JavaScript включен

3. **Адаптивность нарушена:**
   - Проверьте viewport meta tag
   - Убедитесь в корректности media queries
