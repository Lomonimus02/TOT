# Полноэкранная египетская рамка

## Описание
Полноэкранная египетская рамка добавлена на все страницы сайта "Пирамида ТОТА". Рамка отображается поверх всего контента, но не блокирует взаимодействие с элементами страницы.

## Файлы системы рамки

### CSS
- `css/frame.css` - основные стили для рамки
- Подключается на всех страницах после основных стилей

### JavaScript
- `js/frame-manager.js` - менеджер рамки с функциями управления
- Подключается на всех страницах первым среди скриптов

### Изображения
- `images/decor/frame_extracted.png` - изображение египетской рамки

### HTML
- Элемент `<div class="fullscreen-frame"></div>` добавлен в начало body на всех страницах

## Особенности реализации

### Позиционирование
- `position: fixed` - рамка зафиксирована относительно окна браузера
- `z-index: 10000` - рамка отображается поверх контента, но под навигацией
- `pointer-events: none` - рамка не блокирует клики и взаимодействие

### Интерактивная зона входа
- Зона входа расположена в верхней части рамки
- `z-index: 10001` - зона входа отображается поверх рамки
- `pointer-events: auto` - зона входа реагирует на клики
- При наведении показывается подсказка "👤 Вход"
- Клик по зоне открывает модальное окно входа

### Адаптивность
- **Десктоп (>768px)**: `background-size: 100% 100%` - полное покрытие экрана
- **Мобильные устройства (<768px)**: "Умное масштабирование" с горизонтальным увеличением
  - Планшеты (≤768px): `background-size: 120% 100%` - боковые части слегка за экраном
  - Мобильные (≤480px): `background-size: 140% 100%` - боковые части уходят за экран
  - Маленькие экраны (≤375px): `background-size: 160% 100%` - верх/низ выглядят естественно
  - Очень маленькие (≤320px): `background-size: 180% 100%` - максимальная естественность

### Логика "умного масштабирования"
- **Цель**: Верхняя и нижняя части рамки выглядят менее сжатыми на узких экранах
- **Метод**: Увеличение ширины фона (`background-size: X% 100%`) при сохранении высоты
- **Результат**: Боковые части рамки уходят за границы экрана, но не создают прокрутку
- **Преимущество**: Рамка выглядит более естественно на мобильных устройствах

### Ориентация экрана
- **Портретная ориентация**: Усиленное горизонтальное масштабирование (130%-200%)
- **Альбомная ориентация**: Умеренное горизонтальное масштабирование (110%-140%)
- **Специальные настройки** для iPhone SE, iPhone 6/7/8, iPhone Plus
- **Поддержка Retina** дисплеев с высокой плотностью пикселей

### Прозрачность
- **Полностью непрозрачная рамка** на всех устройствах (`opacity: 1`)
- Рамка остается непрозрачной даже при открытии модальных окон
- Никаких изменений прозрачности в зависимости от размера экрана

## Управление рамкой

### JavaScript API
```javascript
// Доступ к менеджеру рамки
const frameManager = window.FrameManager;

// Показать/скрыть рамку
frameManager.showFrame();
frameManager.hideFrame();
frameManager.toggleFrame();

// Управление прозрачностью
frameManager.setOpacity(0.5); // 50% прозрачность
frameManager.resetOpacity();  // Сброс к стандартной прозрачности
```

### CSS классы
```css
.fullscreen-frame.hidden     /* Скрытая рамка */
.fullscreen-frame.modal-active /* Рамка при модальных окнах (30% прозрачность) */
.fullscreen-frame.loaded     /* Рамка после загрузки изображения */
```

### Горячие клавиши (только в режиме разработки)
- `Ctrl + Shift + F` - переключить видимость рамки

## Z-index иерархия
- Рамка: `z-index: 10000`
- Навигация: `z-index: 10001`
- Модальные окна: `z-index: 10002`
- Уведомления: `z-index: 10003`
- Панель редактирования: `z-index: 10004`
- Загрузочный экран: `z-index: 10005`

## Настройка
Для изменения внешнего вида рамки отредактируйте файл `css/frame.css`:
- Прозрачность: свойство `opacity`
- Размер: свойство `background-size`
- Позиция: свойство `background-position`
- Анимации: `@keyframes frameAppear`

## Замена изображения рамки
1. Поместите новое изображение в `images/decor/`
2. Обновите путь в `css/frame.css`:
   ```css
   background-image: url('../images/decor/your-new-frame.png');
   ```
3. Для высокого разрешения добавьте версию @2x

## Поддержка
Все функции рамки логируются в консоль браузера для отладки.
При возникновении проблем проверьте консоль разработчика.
