# Инструкция по развертыванию сайта "Пирамида ТОТА"

## 🚀 Быстрый запуск

### Локальное тестирование
1. Откройте файл `index.html` в любом современном браузере
2. Для полной функциональности используйте локальный веб-сервер:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (если установлен http-server)
   npx http-server
   ```
3. Перейдите по адресу `http://localhost:8000`

## 🌐 Развертывание на хостинге

### Требования к хостингу
- Поддержка статических файлов (HTML, CSS, JS)
- HTTPS сертификат (обязательно для Telegram API)
- Минимум 100 МБ дискового пространства

### Рекомендуемые хостинги
- **GitHub Pages** (бесплатно, с HTTPS)
- **Netlify** (бесплатно, с HTTPS)
- **Vercel** (бесплатно, с HTTPS)
- **Обычный веб-хостинг** с поддержкой HTTPS

### Пошаговое развертывание

#### Вариант 1: GitHub Pages
1. Создайте репозиторий на GitHub
2. Загрузите все файлы проекта
3. В настройках репозитория включите GitHub Pages
4. Ваш сайт будет доступен по адресу: `https://username.github.io/repository-name`

#### Вариант 2: Netlify
1. Зарегистрируйтесь на [netlify.com](https://netlify.com)
2. Перетащите папку с проектом в область загрузки
3. Netlify автоматически развернет сайт и предоставит HTTPS
4. Можете настроить собственный домен

#### Вариант 3: Обычный хостинг
1. Загрузите все файлы в корневую папку сайта через FTP/SFTP
2. Убедитесь, что файл `index.html` находится в корне
3. Настройте HTTPS сертификат (Let's Encrypt или платный)

## 🤖 Настройка Telegram бота

### Создание бота
1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: "Пирамида ТОТА Бот")
   - Введите username бота (например: "pyramid_tota_bot")
4. Сохраните полученный токен (выглядит как: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Получение Chat ID
1. Напишите вашему боту любое сообщение
2. Перейдите по ссылке в браузере:
   ```
   https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates
   ```
   Замените `<YOUR_BOT_TOKEN>` на ваш токен
3. В ответе найдите значение `"id"` в разделе `"chat"` - это ваш chat_id

### Обновление кода
Откройте файл `js/forms.js` и замените:
```javascript
this.telegramBotToken = 'YOUR_BOT_TOKEN'; // Ваш токен бота
this.telegramChatId = 'YOUR_CHAT_ID';     // Ваш chat_id
```

## 🔧 Дополнительные настройки

### SEO оптимизация
Добавьте в `<head>` каждой страницы:
```html
<meta name="description" content="Описание страницы">
<meta name="keywords" content="ключевые, слова">
<meta property="og:title" content="Заголовок для соцсетей">
<meta property="og:description" content="Описание для соцсетей">
<meta property="og:image" content="https://yoursite.com/images/og-image.jpg">
```

### Google Analytics
Добавьте код Google Analytics перед закрывающим тегом `</head>`:
```html
<!-- Google Analytics -->
<script async src="https://www.googletagmanager.com/gtag/js?id=GA_TRACKING_ID"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'GA_TRACKING_ID');
</script>
```

### Яндекс.Метрика
Добавьте код Яндекс.Метрики перед закрывающим тегом `</head>`.

## 🆘 Решение проблем

### Формы не отправляются
- Проверьте токен и chat_id Telegram бота
- Убедитесь, что сайт работает по HTTPS
- Проверьте консоль браузера на ошибки JavaScript

### Анимации не работают
- Убедитесь, что JavaScript включен в браузере
- Проверьте, что файлы CSS и JS загружаются корректно
- Проверьте консоль браузера на ошибки

### Проблемы с адаптивностью
- Проверьте наличие viewport meta tag
- Убедитесь в корректности CSS media queries
- Протестируйте на реальных устройствах
